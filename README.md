# 💧 Water Intake Logger

A simple and beginner-friendly web application that helps users track their daily water intake.

The application allows users to add 250 ml of water, view their daily progress, set a personal water goal, check their water intake history, and save their data using browser Local Storage.

---

## 🌐 Live Project

The project can be run directly in a web browser using the `index.html` file.

---

## 📌 Project Overview

Staying hydrated is important, but it can be difficult to remember how much water we drink during the day.

The **Water Intake Logger** provides a simple interface where users can:

- Track their daily water intake
- Add 250 ml of water with one click
- View progress toward their daily goal
- Set a custom daily water goal
- View today's water intake history
- Reset today's water data
- Save data using Local Storage
- Keep data after refreshing the browser
